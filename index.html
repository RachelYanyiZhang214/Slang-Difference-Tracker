Instead of collecting unrelated “interesting words,” this project asks the same social question in five linguistic contexts — side by side. What changes when people greet, encourage, reassure, recognize effort, or react to something impressive?

The comparison rule
5 languages × 5 situations = 25 parallel observations.

Every category contains every language, in the same order, using the same analytical structure. The phrases do not need to be literal translations. They need to perform a comparable social job.

Read horizontally → one social situation · five linguistic strategies · one comparative insight

How to read the comparison

The website is comparing pragmatic function, not claiming that every speaker in a country behaves the same way.

01

Situation first

Each category starts with a human interaction — not a vocabulary list. This gives every language the same question to answer.

02

Function before translation

Two expressions can perform similar social work even when their literal words are completely different.

03

Pattern, not stereotype

Age, region, relationship, tone and setting all matter. The project identifies communicative patterns without turning them into national personality claims.
